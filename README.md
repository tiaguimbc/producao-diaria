# 👋 Olá, eu sou Débora Moura!

Desenvolvedora focada em transformar processos manuais em fluxos digitais eficientes. Tenho experiência no desenvolvimento de aplicações web completas, integração de bancos de dados em nuvem e automação de hardware.

---

### 🛠️ No que eu trabalho:
* **Desenvolvimento Web:** Criação de interfaces responsivas e modernas utilizando **Tailwind CSS**, **JavaScript** e **HTML5**.
* **Automação & Hardware:** Desenvolvimento de servidores de impressão em **Python** (Brother QL-800) e integração de sistemas de rastreamento de equipamentos.
* **Cloud & Dados:** Implementação de soluções de persistência com **LocalStorage**, **Firebase** e integração avançada com **Google Sheets** via Apps Script.

---

### 🚀 Projetos em Destaque:

#### 📦 [CONTROLE DE ESTOQUE - SCM](https://github.com/seu-usuario/controle-estoque-scm)
Sistema completo de gestão de inventário com classificação de itens (A, B, C, D), upload de fotos e dashboard para controle de insumos.

#### 📊 [Produção Diária - PCP](https://github.com/seu-usuario/producao-diaria-pcp)
Aplicação para gestão de tickets de produção, permitindo o rastreamento de seriais de equipamentos e sincronização em tempo real com planilhas na nuvem.

#### 🖨️ [Automação de Etiquetas - Brother QL-800](https://github.com/seu-usuario/python-printer-server)
Script em Python utilizando a biblioteca **pandas** e o **b-PAC SDK** para automatizar a impressão de etiquetas sequenciais a partir de dados do Excel.
